# CMPE 351 – PostgreSQL Database Project

## Project: Lezzet Durağı

This project designs and implements a PostgreSQL database for a restaurant chain's food ordering, inventory, delivery, and payment operations.

## Milestones
- M1: Requirements, ER Diagram, Normalization
- M2: Schema, Sample Data, SQL Queries, Views
- Final: Procedures, Triggers, Transactions, Security, Testing
